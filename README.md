# WiiMCForwarder
A homemade forwarder for WiiMC for CafeOS!
This is a forwarder package for WiiMC SS/WiiMC.
#INSTALLATION INSTRUCTIONS
You must have an SD card, a modded Wii U, WUP Installer GX2(Please install the one for your specific CFW environment), a PC with either USB drivers(IDK what kind of OS wouldn't have USB drivers tho) or SD card drivers, and a vWii mode that has the HBC and is not bricked. For file setup on the SD card, name your WiiMC or WiiMC SS directory as follows: sd:/apps/wiimc. Yes, I know it's weird that you're naming your WiiMC SS installation wiimc, but the files are hardcoded to expect apps/wiimc. For setup with WUP Installer GX2, please copy all files in the ZIP to sd:/install/*folder for your WiiMC or WiiMC SS installation*. Once you install the package via WUP Install GX2, CONGRATULATIONS, **YOU ARE DONE WITH SETUP**!
